# Tool Visibility and Discovery

- Availability bias: keep general and specialized callable tools active so the model knows they exist. Defer only tools whose invocation is valid inside an owning workflow state, advanced modes with a compact active replacement and searchable explicit names, or control tools whose managed resource does not yet exist.
- State gates: commit execution, goal completion/progress, improvement decisions, plan archival, workflow-change tracking, and review-artifact writing remain inactive until their owning workflow activates them deterministically. `goal_progress` is active for a correlated unattended loop job or while an explicitly supplied foreground plan awaits reviewed materialization; `goal_complete` is active for either foreground or unattended goal state. `plan_archive` is active only while `/do-it` executes or recovers a canonical plan and deactivates after it verifies model-managed closeout: archive, commit, and either the default merge-and-cleanup state or the explicit non-merge retained state. `workflow_complete` is active only for raw `/do-it` closeout and verifies the model-managed commit and merge before owned cleanup.
- Current subagents: expose `subagent_read`, `subagent_write`, and `subagent_teamlead` to roots. A Team Lead sees file-reading tools, `log_analytics`, and read/write execution for subagents; a subagent or depth-two child cannot activate or invoke delegation or workflow tools. Read execution receives only the closed positive allowlist `read`, `grep`, `find`, `ls`, `log_analytics`, `web_search`, and `web_fetch`, independent of agent frontmatter. Tool discovery cannot widen that authority.
- Legacy compatibility: keep `subagent` and `subagent_continue` registered but hidden. Historical resumed calls continue through the compatibility adapter and are never advertised as the current interface, including the hidden `subagent_coordinate` alias. `tool_search` does not activate these historical names.
- Fable restriction: when the exact primary model is `amazon-bedrock/us.anthropic.claude-fable-5`, expose only the applicable current subagent tools and `task`. Keep saved-session continuation unavailable. Let the existing owner expose `goal_progress` during active goal planning, `plan_progress` only during an active `/plan-it` lifecycle, and `plan_archive` only during an active canonical `/do-it` plan, and `workflow_complete` only during active raw `/do-it` closeout. Tool-owner changes made while Fable is selected remain current when the restriction is removed.
- Search behavior: keep `tool_search` active as a fallback for ordinary roots. A non-empty query activates all matching inactive tools by default; list mode never activates tools.
- Catalog: `tool_search` guidance does not advertise historical subagent schemas. Current role-specific tools remain directly discoverable when authority permits them.
- Telemetry: record metadata-only toolset exposure, hashed search decisions, activation results, and tool use. Do not record raw queries, arguments, descriptions, or output.
- Image tools: `image_inspect` and `image_transform` are operator-approved deferred tools. They remain inactive at session start and are activated by a non-empty matching `tool_search`; activation persists for that session and is reset on the next session. Their binary-backed local image operations remain unavailable until explicitly discovered.
- Review boundary: telemetry supports later policy review but does not change activation policy automatically.
